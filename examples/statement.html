A widget is not a fix.

What the AccessibleWeb Widget does, what it does not do, and where the real work of accessibility happens.

What this widget does

It gives visitors controls for how a page looks and reads to them: text size, spacing, contrast, a more readable font, reading aids, and text to speech. These are personal preferences, like the settings already built into a browser or a phone, put where they are easy to find.

Choices are saved in the visitor's own browser. Nothing is tracked or sent anywhere.

What it does not do

It does not repair a website. It does not change the site's code, describe images that have no description, free a keyboard user who is stuck, or correct the order in which a screen reader reads a page.

It does not make a site conform to WCAG, the ADA, Section 508, the European Accessibility Act, or any other standard or law. No widget or overlay can. We support the Overlay Factsheet.

If something on a site did not work for you

If you came here from a website where you could not read, reach, or use something, the problem is in that site, not in you and not in this widget. Please tell the site's owner. They are the ones who can fix it.

The options in the widget may help in the meantime, but they are not the fix.

If you own the site

Accessibility is built into a site: meaningful HTML, text alternatives, full keyboard support, enough contrast, and testing with people who use assistive technology. This widget is a complement to that work, never a substitute.

Start by finding what is broken. The free, open source Accessible Web Scanner checks your pages against WCAG rules and lists each problem with the element it is on. The widget also has a built-in check for the page you are on; see the Audit page.

Automated checks find only some problems. The rest need a person, ideally one who uses a screen reader, a keyboard, or magnification every day.

This widget's own accessibility

The widget's panel is built to work with a keyboard and with screen readers, and it is tested automatically on every change. If you find a barrier in the widget itself, please open an issue on GitHub.
